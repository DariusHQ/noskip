# Code of Conduct

noskip is a small project with a simple rule: be the kind of collaborator you would want reviewing your code.

- Be respectful and assume good intent. Critique code and ideas, not people.
- No harassment, insults, discrimination or personal attacks, in any form or channel.
- Keep discussions on topic and help newcomers find their way.
- Sharing an agent's cheat in an issue is welcome. Shaming a person is not.

Maintainers may edit or remove contributions and block participants who don't follow these rules.

Report problems privately through a
[GitHub security advisory](https://github.com/DariusHQ/noskip/security/advisories/new) or by contacting
the maintainer on GitHub ([@DariusHQ](https://github.com/DariusHQ)). Reports are handled confidentially.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
